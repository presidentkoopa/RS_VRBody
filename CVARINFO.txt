// ---- the pose, TRANSLATED, for whoever is actually drawing the hand --------
//
// The two above are a POSE INDEX in this mod's vocabulary. These are the FRAME
// NUMBER that index resolves to on the hand mesh currently in the slot, and
// they exist because those are not the same thing across packages:
// RS_WorldHands numbers eleven poses and then jumps to 1289 where the
// manipulation set really lives, while this mod numbers twenty contiguously.
// The two agree up to index 6 and diverge from 7 -- which is every pose worth
// having. An index passed across that boundary makes the wrong shape, silently.
//
// Written every tic by RS_VRBody (body_rig.zs, publishPose) whether or not
// this mod drew the hand. -1 means "nothing to say", which leaves the hand to
// its own idle behaviour rather than forcing it open.
//
// nosave: a derived value, recomputed every tic. Persisting it would restore a
// stale frame for one tic on load, and one tic of the wrong hand shape at a
// map start is exactly the kind of thing nobody ever tracks down.
nosave int rs_body_poseframe_main = -1;
nosave int rs_body_poseframe_off  = -1;
